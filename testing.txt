Test Case 2 - Large project with discount
Input Values:
- Client Name: Orion Labs
- Labor Hours: 20
- Material Cost: 500
- Project Type: Large
- Discount: 10

Expected Results:
- Labor Cost = 20 x 75.00 = 1,500.00
- Base Subtotal = (1,500.00 + 500.00) x 1.30 = 2,600.00
- Discount = 10% of 2,600.00 = 260.00
- Subtotal after discount = 2,340.00
- Tax = 2,340.00 x 0.07 = 163.80
- Total = 2,503.80
- Estimated Days = Ceiling(20 / 8) = 3

Actual Results:
- Program displayed discount line and subtotal after discount correctly
- Program displayed Tax 163.80 and Total 2,503.80
- Program displayed Estimated Days as 3
